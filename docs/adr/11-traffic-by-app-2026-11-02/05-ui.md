# 5. The screens: from the canvas to the Swift files

**Status:** Proposed (not built).

## Context

The design is the canvas "LocalRouter menu bar redesign":
<https://claude.ai/artifact/FsPnM9uRe3Ev3xG8sfkujT>. It has one artboard per
screen. This file maps each artboard to the code and lists where the build
must differ from the drawing.

### 5.1 Where the build differs from the canvas

| Canvas | Build | Why |
|---|---|---|
| domains under each app, "41 domains" | addresses with owner and place, "41 addresses"; host names for router and proxy traffic | nettop has no host names ([01](01-app-traffic.md), 1.1) |
| "Top domains" | "Top owners" | same |
| Settings: "Uses the LocalRouter network filter" and "Open System Settings" | "Uses nettop, which comes with macOS. Off by default." and no System Settings row | no network filter in this ADR |
| colored letter tiles as app icons | the real app icon (`NSWorkspace.icon(forFile:)`); a letter tile only when there is no path | the canvas could not use real icons |
| `Google LLC · EQHXZ8M8AV` | the signer and team id read by the check | sample data in the canvas |
| all numbers | real numbers | sample data |

### 5.2 The menu

`AppMenu.Action` gains `reviewApp(String)` (an executable path),
`showApps` and `openTrafficMap`. `AppMenu.Context` gains
`trafficSummary: String?` ("↓ 431 MB, ↑ 96.5 MB last hour", nil when the
sampler is off) and `appsToReview: [AppReview]`. The Traffic group is shown
only when the sampler is on; **Review \<app\>…** only when an app needs
review, one item per app, at most three.

### 5.3 Settings → Traffic

`SettingsPage.traffic`, after `scripts`, symbol `chart.bar`, keywords
`["traffic", "apps", "nettop", "history", "map", "places", "db-ip",
"virustotal", "api key", "code signature", "notarized", "trusted", "ask ai",
"claude", "chatgpt"]`.

Groups, from the artboard:

1. **Monitoring**: See every app on this Mac; Keep history 1 day / 7 days /
   30 days with the size on disk and **Clear history**; Show places on the map
   with the database date, **Update** and the DB-IP credit; This Mac is in.
2. **App checks**: Check code signatures; Look up new programs on
   VirusTotal; API key (secure field, "Saved in Keychain", lookups today, link
   to get a free key); When a program needs review (red dot, notification,
   ad-hoc); Trusted programs with **Edit list…**.
3. **Ask AI**: "What is this?" opens Claude / ChatGPT / Both; Put network
   addresses in the question.

### 5.4 Empty and off states

| State | Apps view shows |
|---|---|
| `traffic` is off | a card: "See which apps use the network. LocalRouter reads it with nettop, which comes with macOS. Nothing leaves this Mac." and **Turn On** |
| sampler `restarting` | the last data, and a line "Reading traffic again…" with the error |
| daemon not running | the same text as the Requests view |
| no traffic yet | "No traffic in the last hour." |
